# Sistema de Orientación Institucional

## ¿Qué es el proyecto?
Es una aplicación de consola desarrollada en Python diseñada para asistir a estudiantes universitarios de primer ingreso en la resolución de dudas frecuentes sobre la vida académica, ubicación en el campus, uso de plataformas digitales, trámites de becas y servicios de asesoramiento.

## ¿Para qué sirve?
El sistema centraliza las preguntas más comunes de los estudiantes a través de una interfaz interactiva de menús navegables. Permite consultar rápidamente información sobre:
- Ubicación de aulas y edificios en el campus.
- Manejo de plataformas digitales (Canvas, Portal de Estudiantes, Correo Institucional).
- Contacto e información sobre profesores.
- Requisitos y procesos de becas y servicio becario.
- Períodos y evaluación de actividades académicas especiales (Semana Tec).
- Orientación y tutorías académicas.
